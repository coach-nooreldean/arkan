## 🌟 نظرة عامة (Overview)

**تطبيق أركان (Arkan)** هو تطبيق إسلامي عصري متكامل صُمم ليكون دليلك اليومي المعين على الطاعات وذكر الله. يتميز التطبيق بتصميم راقٍ وحديث، واجهة مستخدم مريحة للعين تدعم النمطين الداكن الفاخر (Obsidian Dark) والفاتح الأنيق (Light Mode)، بالإضافة إلى توافقه الكامل مع جميع المنصات (Android, iOS, Windows, Linux, macOS, Web).

يعتمد التطبيق على أحدث التقنيات وأفضل الممارسات البرمجية عبر إطار العمل **Flutter** مع بنية **Clean Architecture** ونظام إدارة الحالة **BLoC/Cubit** لضمان أعلى مستويات الأداء والسلاسة.

## ✨ المميزات الرئيسية (Key Features)

### 📖 المصحف الشريف وتدبر القرآن
* **المصحف العثماني / المدني:** صفحات مصحف عالية الدقة ومريحة للقراءة مع التكبير والتنقل المرن.
* **فهارس متكاملة:** فهرس كامل للسور، الأجزاء، والأحزاب مع إمكانية البحث الفوري والوصول السريع.
* **تدوين الملاحظات والخواطر:** إمكانية حفظ الآيات، تدوين الفوائد والتأملات، وحفظ العلامات المرجعية (Bookmarks).
* **متابع الختمة:** تتبع تقدمك في القراءة وختم القرآن الكريم مع دعاء ختم القرآن المأثور.

### ⏱️ مواقيت الصلاة الدقيقة والأذان
* **حساب دقيق:** حساب أوقات الصلوات الخمس والشروق اعتماداً على الموقع الجغرافي (GPS) أو التحديد اليدوي.
* **الهيئات الفقهية:** دعم طرق الحساب الفقهية العالمية (رابطة العالم الإسلامي، أم القرى، الهيئة المصرية، وغيرها).
* **العد التنازلي والتنبيهات:** مؤقت تنازلي حتى الصلاة القادمة مع إشعارات وتنبيهات أذان مرنة.

### 🧭 بوصلة القبلة الذكية (Qibla Compass)
* **استشعار فوري:** توجيه دقيق ومباشر نحو الكعبة المشرفة باستخدام مستشعرات البوصلة المدمجة في الجهاز وحسابات الزوايا الجغرافية الدقيقة.

### 📿 الأذكار والأدعية اليومية
* **مكتبة أذكار جامعة:** أذكار الصباح والمساء، أذكار النوم، الاستيقاظ، أدعية الصلاة، والأذكار النبوية اليومية.
* **عداد تفاعلي ذكي:** واجهة تفاعلية لكل ذكر مع اهتزاز لمسي (Haptic Feedback) وصوت عند إتمام التكرار المطلوب.

### 🪨 السبحة الإلكترونية المتطورة (Smart Tasbih)
* واجهة تسبيح عصرية ومرنة مع مؤثرات بصرية وصوتية.
* إحصائيات يومية، أهداف تسبيح قابلة للتخصيص، وسجل دائم لمرات الاستغفار والحمد والتكبير.

### 📊 سجل ومتابع الطاعات (Worship Tracker)
* متابعة الصلوات الخمس في أوقاتها (في المسجد، جماعة، فردية).
* تتبع السنن الرواتب، صيام التطوع، قيام الليل، وصلاة الضحى لتحفيز الاستمرارية والثبات.

### 📜 الأربعون النووية وأسماء الله الحسنى
* **الأربعون النووية:** نصوص الأحاديث كاملة مع الشروح والفوائد المستنبطة لكل حديث.
* **أسماء الله الحسنى:** استعراض الأسماء الـ 99 مع معانيها وتأملاتها الإيمانية.

### 🪙 نظام مكافآت ونقاط أركان (Arkan Coins)
* نظام تفاعلي يكافئ المستخدم بالنقاط والأوسمة عند أداء العبادات والأذكار بانتظام، مما يضفي بعداً تحفيزياً جميلاً لليوميات الإيمانية.

### 🌐 بوابة الويب (Web Portal)
* لوحة تحكم وموقع ويب تفاعلي مبني بتقنيات **React**, **Vite**, و **TailwindCSS** لتقديم تجربة متناسقة على المتصفح.

## 🏗️ البنية التقنية (Architecture & Tech Stack)

تم بناء المشروع باتباع مبادئ **Clean Architecture** و **Feature-Driven Architecture** لتحقيق قابلية التوسع والصيانة وسهولة الاختبار:

```
lib/
├── core/                     # البنية التحتية المشتركة (Shared Infrastructure)
│   ├── constants/            # الثوابت والقيم العامة
│   ├── extensions/           # دوال التوسعة (Extensions)
│   ├── routing/              # نظام التوجيه والتنقل (GoRouter)
│   ├── services/             # خدمات الإشعارات، الصوت، والموقع
│   ├── theme/                # ألوان التطبيق والخطوط ونمط الـ Dark/Light Mode
│   ├── utils/                # أدوات مساعدة عامة
│   └── widgets/              # عناصر الواجهة المشتركة والقابلة لإعادة الاستخدام
│
├── features/                 # وحدات الميزات المستقلة (Feature Modules)
│   ├── islamic_hub/          # وحدة الخدمات الإسلامية (المصحف، الصلاة، الأذكار، القبلة)
│   │   ├── data/             # مصادر البيانات والمستودعات (Models, Repositories)
│   │   ├── domain/           # منطق الأعمال والكيانات (Entities, Use Cases)
│   │   └── presentation/     # واجهات المستخدم وإدارة الحالة (Screens, Cubits, Widgets)
│   ├── rewards/              # وحدة النقاط والمكافآت (Arkan Coins & Badges)
│   └── main_navigation/     # شريط التنقل الرئيسي والهيكل العام للتطبيق
│
├── shared/                   # أدوات ووظائف مساعدة مشتركة
└── main.dart                 # نقطة الانطلاق وإعدادات التطبيق الأساسية
```

### أبرز الحزم والتقنيات المستخدمة:
| التقنية | الاستخدام |
| :--- | :--- |
| **Flutter 3.5+** | إطار العمل الأساسي متعدد المنصات |
| **Flutter BLoC / Cubit** | إدارة الحالة (State Management) الموثوقة والقابلة للفصل |
| **GoRouter** | نظام التوجيه الديكلاريتيفي ودعم الروابط العميقة |
| **ScreenUtil & LayoutBuilder** | تصميم متجاوب (Responsive Design) يلائم كل مقاسات الشاشات والهواتف والأجهزة اللوحية والحواسيب |
| **Easy Localization** | دعم كامل للغتين العربية والإنجليزية مع اتجاه النصوص RTL/LTR |
| **Just Audio & AudioPlayers** | تشغيل التلاوات والأذان والمؤثرات الصوتية |
| **Local Notifications & Timezone** | جدولة التنبيهات وإشعارات الأذان في أوقاتها المحددة |
| **Geolocator & Compass Sensors** | تحديد الموقع الجغرافي وحساب اتجاه القبلة بدقة |

## 🚀 البدء والتشغيل (Getting Started)

### المتطلبات الأساسية (Prerequisites)
1. تثبيت **[Flutter SDK](https://docs.flutter.dev/get-started/install)** (الإصدار `>= 3.5.0`).
2. تثبيت **Git**.
3. بيئة تطوير مناسبة: **VS Code** أو **Android Studio** مع إضافات Flutter & Dart.

### خطوات التثبيت والتشغيل المحلي (Setup & Run)

1. **استنساخ المستودع (Clone repository):**
   ```bash
   git clone https://github.com/coach-nooreldean/arkan.git
   cd arkan
   ```

2. **تثبيت حزم فلاتر (Install Dependencies):**
   ```bash
   flutter pub get
   ```

3. **تشغيل التطبيق (Run the App):**
   * للتشغيل على جهاز أو محاكي أندرويد:
     ```bash
     flutter run
     ```
   * للتشغيل على الويب:
     ```bash
     flutter run -d chrome
     ```
   * للتشغيل على سطح المكتب (Windows / Linux / macOS):
     ```bash
     flutter run -d windows
     # أو
     flutter run -d linux
     ```

### تشغيل بوابة الويب (Web Portal)
يحتوي المشروع على مجلد `web_portal` مبني بـ React و Tailwind:
```bash
cd web_portal
npm install
npm run dev
```
